# Enterprise Sales Data Warehouse & Analytics

## Overview

This project demonstrates enterprise-scale data modeling and business intelligence using Power BI.

## Features

- Star Schema Modeling
- Fact & Dimension Tables
- Power Query Data Transformation
- DAX Measures
- Row-Level Security (RLS)
- Sales Analytics
- Inventory Analytics
- Campaign Analytics

## Tech Stack

- Power BI
- Power Query
- DAX
- Excel
