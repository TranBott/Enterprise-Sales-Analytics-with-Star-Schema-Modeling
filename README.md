# \# Enterprise Sales Analytics with Star Schema modeling

# 

# An enterprise-scale Business Intelligence solution built using Power BI, focusing on dimensional data modeling, data transformation, and analytical reporting. The project demonstrates industry-standard data modeling practices by transforming raw operational data into an optimized semantic model for scalable business analytics.

# 

# \---

# 

# \## Project Overview

# 

# This project converts a complex dataset consisting of 23 interconnected tables into a clean and optimized Star Schema for analytical reporting. It emphasizes data modeling best practices, reusable business logic, and secure reporting to support efficient business intelligence workflows.

# 

# \---

# 

# \## Key Features

# 

# \- Designed a scalable \*\*Star Schema\*\* using Fact and Dimension tables

# \- Transformed and modelled raw data using \*\*Power Query\*\*

# \- Built reusable \*\*DAX Measures\*\* for business calculations

# \- Created a centralized \*\*Date Dimension\*\* for time intelligence

# \- Implemented \*\*Row-Level Security (RLS)\*\* for secure data access

# \- Optimized the semantic model for efficient analytical reporting

#
